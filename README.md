# 2D War Strategy - Multiplayer

Многопользовательская версия игры 2D War Strategy с полной синхронизацией через WebSocket.

## Развертывание на Render.com

### Шаг 1: Создание репозитория на GitHub

1. Создайте новый репозиторий на GitHub
2. Скопируйте файлы из папки `war-strategy-multiplayer` в этот репозиторий:
   - `package.json`
   - `server.js`
   - `index.html`

### Шаг 2: Развертывание на Render

1. Зайдите на [render.com](https://render.com) и войдите в аккаунт
2. Нажмите "New +" → "Web Service"
3. Подключите ваш GitHub репозиторий
4. Настройки:
   - **Name**: war-strategy-multiplayer (или любое другое)
   - **Region**: выберите ближайший регион
   - **Branch**: main
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `node server.js`
5. Нажмите "Create Web Service"

### Шаг 3: Настройка переменных окружения (опционально)

Если нужно изменить порт, добавьте переменную окружения:
- Key: `PORT`
- Value: `3000` (или другой порт)

## Локальный запуск

### Установка зависимостей

```bash
npm install
```

### Запуск сервера

```bash
npm start
```

Или:

```bash
node server.js
```

Сервер запустится на порту 3000 (или на порту, указанном в переменной окружения `PORT`).

Откройте браузер и перейдите по адресу:
```
http://localhost:3000
```

## Как играть

1. Откройте игру в браузере
2. Нажмите "Присоединиться к игре"
3. Вы попадёте на полигон с другими игроками
4. **Управление**:
   - W, A, S, D - движение
   - Мышь - прицеливание
   - ЛКМ - огонь из всех орудий
   - Колесо мыши, +/- - зум

## Особенности мультиплеера

- **Полная синхронизация**: позиция, угол, скорость всех игроков
- **Синхронизация выстрелов**: все снаряды видны всем игрокам
- **Синхронизация урона**: HP, модули, затопление, пожары синхронизируются
- **Синхронизация смерти/респавна**: все игроки видят состояние друг друга
- **Лобби**: список подключённых игроков до начала игры

## Технологии

- **Backend**: Node.js + Express
- **WebSocket**: Socket.io
- **Frontend**: HTML5 Canvas + JavaScript
- **Styling**: TailwindCSS

## Решение проблем

### Порт уже занят

Если при локальном запуске появляется ошибка "Port already in use", измените порт в `server.js` или установите переменную окружения `PORT`:

```bash
set PORT=3001 && node server.js
```

### Проблемы с подключением

Убедитесь, что:
- Сервер запущен
- Порт не блокируется файрволом
- Используется правильный URL при подключении
